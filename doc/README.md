# Archived vendor reference documents

This directory contains historical device, simulator, and tool documentation used during early experiments. It is not required to build or run the current Arduino UNO Q + KX134 contest application.

Current project documentation starts at [`../docs/README.md`](../docs/README.md).

Several files here are third-party PDFs or text conversions. Their redistribution rights have not been established by this repository. Review each vendor's terms before making a public release; remove or replace files with links when redistribution is not permitted.
