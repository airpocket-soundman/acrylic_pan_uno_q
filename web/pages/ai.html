05 / AI model strategy

小さく収めるのではなく、
実測精度を伸ばす。

UNO Q版のAIは、ML63Q2557のノード数、16 KB RAM、bfloat16、1隠れ層ELM、Solist-AI形式に制約されません。旧モデルは比較用baselineとして保存し、QRB2210の計算能力に合わせて時系列・周波数情報をより多く使います。

採用原則モデル規模ではなく、別セッション実測データの精度、座標誤差、確信度、条件変化への頑健性、UNO Q実機のp95 latencyで決定します。

モデルを育てる順序

B0

再現可能なbaseline

旧128-64-8 ELM、ロジスティック回帰、勾配ブースティングを同じsplitで評価し、移植前後の比較点を作ります。

B1

3軸 1D CNN / TCN

生波形の立上り、減衰、軸間位相差を学習します。窓長と受容野を広げ、単一Z軸・128特徴の制限を外します。

B2

スペクトログラムCNN

STFTや複数帯域を入力し、位置ごとの固有モード差と時間変化を同時に評価します。

B3

multi-task model

8領域、連続XY、強度、confidenceを共有encoderから出力します。必要な場合だけ二枝構造、ensemble、蒸留を試します。

入力と出力

INPUT

波形を削り過ぎない

KX134の3軸時系列を正本とし、生波形、STFT、帯域エネルギーを比較します。サンプルレート、窓長、LPFも精度とlatencyを見て再設計できます。

OUTPUT

分類＋回帰＋不確かさ

8クラスを互換出力として残しながら、XY座標、打撃強度、confidenceを追加します。未知／曖昧打撃を無理に8点へ割り当てません。

選定指標

領域分類macro F1 / balanced accuracyクラス偏りの影響を抑えて比較
位置回帰XY median / p95 error平均だけでなく大外れも測る
信頼性calibration / reject accuracyconfidenceが実際の正しさに対応するか
頑健性別日・別打撃者・再取付け同じ収録内の暗記を排除
実機性能前処理込みp50 / p95 latency連打時の欠落率、CPU、メモリも記録

旧Solist AIの位置付け

既存ELM、ダミーモデル、FEM合成評価は削除せず、通信・前処理・回帰試験と移植比較に利用します。ただし合成データ100%や旧570ノード目安を、UNO Q版の性能根拠または上限にはしません。

決定の正本は 開発方針。データ作成とsplit規則は 学習データ方針 を参照してください。
